# Life Accelerator

Personal productivity and life management dashboard.

## Features

- Life balance wheel visualization
- Monthly reflections and goals
- Habit tracking
- Weekly planning
- Goal management
- Progress analytics

## Live Demo

Visit: https://htsgladiatis.github.io/life-accelerator/

## Usage

Open the website in any modern web browser. All data is stored locally in your browser's localStorage.
